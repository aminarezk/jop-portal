# Job Portal System

A web-based Job Portal application that allows users to search for jobs, apply for positions, and manage their profiles through a secure authentication system.

## Features

### Authentication & Authorization

* Secure user registration and login system.
* Role-based access control for users and administrators.

### Job Search & Listings

* Search for jobs by job title or keywords.
* View detailed job descriptions and requirements.
* Browse available job opportunities.

### Job Application System

* Apply for jobs directly through the platform.
* Upload CV/Resume during the application process.
* Track application status.

### User Dashboard

* Personalized dashboard for users.
* View applied jobs and application history.
* Manage profile information and CV.

### Translation

* Multi-language support using Laravel Localization.

## Technologies Used

* Laravel 7
* PHP
* MySQL
* Bootstrap
* REST API (if used)
* Postman (for API testing if applicable)
